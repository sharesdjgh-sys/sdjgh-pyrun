기획서 내용 (아래 형식으로 작성):

[배경 및 필요성]
현재 고등학교 정보 교과에서 인공지능 학습의 선수 과정으로 파이썬 프로그래밍을 지도하고 있으나, 텍스트 기반의 코드 실행 결과(콘솔 출력)만으로는 영상 및 시각적 콘텐츠에 익숙한 현 세대 학생들의 흥미와 동기를 유발하기 어려운 실정이다. 블록코딩(스크래치 등)이 학생들에게 인기 있는 이유는 코드 입력 즉시 캐릭터가 반응하는 시각적 피드백 구조에 있으나, 텍스트 코딩 환경(Google Colab 등)은 이러한 즉각적 시각 반응이 부재하여 학습 흥미 저하로 이어지고 있다. 또한 다수의 정보 교사가 동일한 어려움을 겪고 있어, 개별 교사가 자체적으로 흥미 유발 도구를 제작하기 어려운 구조적 문제도 존재한다. 이에 파이썬 기초 커리큘럼(출력, 변수, 연산자, 자료형, 조건문, 반복문, 함수, 클래스, 모듈)을 시각적·인터랙티브하게 학습할 수 있는 웹 기반 서비스의 개발이 필요하다.

[해결 방안]
본 프로젝트는 바이브코딩(Vibe Coding) 방식을 활용하여 파이썬 학습용 인터랙티브 웹 서비스를 개발한다. 핵심 해결 전략은 다음과 같다.

1. 블록코딩의 즉각적 시각 반응 구조를 텍스트 코딩 환경에 이식: 학생이 파이썬 코드를 작성하고 실행하면, 화면 내 AI 로봇 캐릭터가 코드 내용에 맞게 즉각적으로 애니메이션으로 반응하는 구조를 구현한다.

2. Gemini 2.5 Flash API를 활용한 실시간 AI 피드백: 코드 실행 결과에 따라 AI 로봇이 말풍선으로 칭찬·개념 설명(성공 시) 또는 힌트·오류 안내(실패 시)를 고등학교 1학년 눈높이에 맞게 제공한다.

3. 게이미피케이션 적용으로 자기주도 학습 동기 유발: 개념별 클리어 뱃지, 축하 애니메이션, 나의 성장 기록 페이지 등을 통해 경쟁 부담 없이 성취감을 느낄 수 있는 학습 환경을 제공한다.

4. 확장 가능한 구조 설계: 1차로 학생용 화면을 완성하고, 추후 교사가 자신의 커리큘럼 코드를 업로드하면 서비스가 자동으로 적용되는 관리자 모드를 2차 개발로 추가하여 다수의 정보 교사가 활용 가능한 범용 플랫폼으로 확장한다.

[주요 기능]
1. 코드 에디터 (좌측 화면)
- 줄 번호가 표시되는 에디터 스타일의 파이썬 코드 입력창
- 초록색 실행 버튼
- 예제 불러오기 버튼: 현재 단원의 커리큘럼 예제 코드를 즉시 불러오는 기능
- 코드 초기화 버튼: 작성 중인 코드를 초기 상태로 되돌리는 기능

2. AI 로봇 캐릭터 애니메이션 (우측 화면)
- 귀여운 2D AI 로봇 캐릭터가 화면 중앙에 상시 표시
- 파이썬 개념별 시각적 반응:
  · print문 실행 → 로봇 말풍선에 출력 결과 표시
  · 변수 할당 → 캐릭터 머리 위에 변수 값 표시
  · for문 실행 → range 숫자만큼 로봇 보행 애니메이션 반복
  · if문 실행 → 조건이 True이면 점프, False이면 고개 젓기 애니메이션
  · 함수 정의 및 호출 → 함수에 대응하는 로봇 동작 애니메이션
  · 클래스 정의 → 전사, 궁수 등 캐릭터가 화면에 추가 등장

3. AI 실시간 피드백 (Gemini 2.5 Flash API 연동)
- 코드 실행 성공 시: 칭찬 메시지 + 해당 개념의 쉬운 설명을 말풍선으로 제공
- 코드 실행 실패 시: 오류 원인 힌트 + 수정 방향 안내를 말풍선으로 제공
- 피드백 톤: 고등학교 1학년 눈높이에 맞게 짧고 친근하게 생성

4. 게이미피케이션 및 성장 기록
- 개념별 클리어 뱃지: 각 파이썬 개념(출력, 변수, 조건문, 반복문, 함수, 클래스 등)을 처음 성공하면 뱃지 지급 및 로봇 축하 애니메이션 재생
- 나의 성장 기록 페이지: 클리어한 개념 목록, 획득 뱃지 현황, AI 피드백 히스토리를 한눈에 확인
- DB 연동: 학생별 진도, 획득 뱃지, AI 피드백 히스토리를 데이터베이스에 저장하여 누적 관리

5. (2차 개발) 교사용 관리자 모드
- 교사가 자신의 파이썬 커리큘럼 코드를 업로드하면 서비스에 자동 적용
- 단원별 예제 코드 등록 및 관리 기능
- 학급 학생들의 학습 진도 현황 확인 기능

[기대 효과]
1. 학습 흥미 및 몰입도 향상: 텍스트 출력에서 벗어나 캐릭터 애니메이션과 즉각적인 AI 피드백을 통해 '내 코드가 살아있다'는 경험을 제공함으로써 파이썬 학습에 대한 흥미와 몰입도를 높인다.

2. 자기주도 학습 능력 강화: 게이미피케이션 요소(뱃지, 성장 기록)와 AI 피드백 히스토리를 통해 학생이 스스로 학습 성취를 확인하고 부족한 부분을 재도전하는 자기주도 학습 습관을 형성한다.

3. 교사의 수업 효율성 제고: 학생이 코드 오류 시 AI 로봇으로부터 즉각적인 힌트를 받을 수 있어 교사가 개별 학생 질문에 일일이 응대해야 하는 부담이 줄어들고, 수업 흐름이 원활하게 유지된다.

4. 정보 교육 현장의 범용 도구로 확장: 교사 커리큘럼 업로드 기능(2차 개발)이 추가되면, 전국의 정보 교사가 자신의 수업 내용에 맞게 서비스를 활용할 수 있는 범용 파이썬 학습 플랫폼으로 발전할 수 있다.

5. AI 학습 연계 기반 마련: 파이썬 기초를 흥미롭게 학습한 학생들이 이후 인공지능 교과로 자연스럽게 연결되는 학습 경험을 제공하여, 고교 정보 교과의 AI 리터러시 교육 효과를 높인다.
