[ 파이썬 학습 서비스 — 최종 제출 요약 ]
작성자: 임성민
작성일: 2026. 6. 18.
대상 공모전: 정보교과 교육과정 수업 방식 개선

═══ 문제 정의 ═══
한 줄 소개: 파이썬 학습에 흥미를 잃은 고등학생을 위해 AI 로봇 캐릭터와 게이미피케이션으로 코딩을 시각적·인터랙티브하게 경험하게 하는 웹 학습 서비스
해결하려는 문제: 고등학교 1학년 정보 교과에서 파이썬을 텍스트 출력 중심으로 학습할 때 학생들이 흥미와 성취감을 느끼지 못하는 문제. 블록코딩처럼 코드 실행 결과가 캐릭터의 시각적 반응으로 즉각 표현되지 않아 '내가 뭔가 만들었다'는 느낌을 받기 어려운 것이 핵심 원인임.
배경 및 필요성: 현재 정보 교과 현장에서는 Google Colab 기반의 텍스트 출력 중심 파이썬 수업이 진행되고 있음. 영상과 시각적 자극에 익숙한 Z세대 학생들에게 텍스트만 출력되는 코딩 환경은 흥미 유발이 어려움. 반면 스크래치 같은 블록코딩 환경은 명령 즉시 캐릭터가 반응하여 학습 몰입도가 높음. 이 격차를 해소할 수 있는 텍스트 코딩 전용 인터랙티브 웹 서비스가 필요하며, 개발자 출신 정보 교사가 바이브코딩으로 직접 제작하여 다른 정보 선생님들도 활용할 수 있는 범용 도구로 확장 가능성을 가짐.

기능 개요:
왼쪽 파이썬 코드 에디터와 오른쪽 AI 로봇 캐릭터 애니메이션 화면으로 구성된 웹 서비스. 학생이 코드를 실행하면 print문·변수·반복문·조건문·함수·클래스 등 개념에 따라 로봇이 말풍선·걷기·점프·캐릭터 등장 등으로 시각적 반응을 보여줌. Gemini 2.5 Flash API를 연동하여 코드 성공 시 칭찬과 개념 설명, 오류 시 힌트를 로봇 말풍선으로 제공. 개념 클리어 시 뱃지 지급 및 축하 애니메이션, 학생별 진도·뱃지·AI 피드백 히스토리를 DB에 저장하는 게이미피케이션 적용. 나의 성장 기록 페이지에서 학습 이력 확인 가능. 추후 선생님용 커리큘럼 업로드 관리자 모드 확장 예정.

  SW와의 관계: 정보 교과 수업에서 파이썬을 처음 배우는 학생으로, AI 학습 서비스의 핵심 사용 대상입니다.

  SW 사용 목적: 파이썬 커리큘럼 코드를 서비스에 연동하여 수업에 활용하고, 학생들의 학습 진도와 AI 피드백 히스토리를 관리합니다.
  SW와의 관계: 여고 정보 수업을 담당하며, 학생 흥미 유발을 위해 인터랙티브 학습 도구를 직접 개발하려는 현직 교사입니다.

  SW 사용 목적: 코드 실행 결과에 따라 칭찬·힌트 피드백을 생성하고, AI 로봇 캐릭터의 말풍선을 통해 학생에게 개념을 설명합니다.
  SW와의 관계: Gemini 3.5 Flash API로 연동되어 서비스의 핵심 학습 피드백 엔진 역할을 담당합니다.

═══ 기능 설계 ═══
[ 기능 1: 코드 실행 및 AI 로봇 시각화 ]
기능 설명: 학생이 파이썬 코드를 입력하고 실행하면 귀여운 AI 로봇 캐릭터가 코드 내용에 따라 애니메이션으로 반응하는 핵심 기능. print문은 말풍선, 변수는 머리 위 표시, for문은 걷기, if문은 점프/고개젓기, 함수/클래스는 캐릭터 등장으로 시각화

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 왼쪽 코드 입력창에 파이썬 코드를 작성하고 초록색 실행 버튼을 눌러요.
    입력 데이터: 학생이 작성한 파이썬 코드 (예: print('안녕'), for i in range(5))
  단계 2 (시스템 처리) — 앱이 입력된 코드를 분석해서 어떤 파이썬 개념이 사용됐는지 파악해요. (print문인지, for문인지, if문인지 등)
    입력 데이터: 코드 텍스트, 사용된 파이썬 개념 종류
    출력/결과: 감지된 개념 유형 (예: print문, for문, if문, 함수, 클래스)
  단계 3 (조건 분기) — 코드 실행이 성공했는지 실패했는지에 따라 로봇의 반응이 달라져요. 성공하면 칭찬 모드, 오류가 있으면 힌트 모드로 나뉘어요.
    입력 데이터: 코드 실행 성공 여부 (성공 / 오류 발생)
  단계 4 (결과 출력) — 오른쪽 화면에서 AI 로봇 캐릭터가 코드 개념에 맞게 애니메이션으로 반응해요. print문이면 말풍선, for문이면 그 숫자만큼 걷기, if문이면 점프 또는 고개 젓기, 클래스면 새 캐릭터 등장으로 화면에 나타나요.
    출력/결과: 로봇 애니메이션 (말풍선 텍스트, 걷기/점프/고개젓기 동작, 새 캐릭터 등장)
  단계 5 (시스템 처리) — Gemini 2.5 Flash AI가 학생의 코드와 실행 결과를 분석해서 고등학교 1학년 눈높이에 맞는 피드백 메시지를 만들어요. 성공하면 칭찬과 개념 설명, 실패하면 어디를 고치면 좋을지 힌트를 생성해요.
    입력 데이터: 학생 코드, 실행 결과, 오류 메시지 (있을 경우)
    출력/결과: AI가 생성한 피드백 메시지 (칭찬+개념 설명 또는 힌트 안내)

[ 기능 2: Gemini AI 피드백 시스템 ]
기능 설명: Gemini 2.5 Flash API를 연동하여 코드 실행 결과에 따라 AI 로봇이 말풍선으로 피드백 제공. 코드 성공 시 칭찬 메시지와 개념 설명, 오류 발생 시 힌트 방식의 친절한 안내를 고등학교 1학년 눈높이에 맞게 생성

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 코드 입력창에 파이썬 코드를 작성하고 초록색 실행 버튼을 눌러요.
    입력 데이터: 학생이 작성한 파이썬 코드 (예: print('안녕하세요'))
  단계 2 (시스템 처리) — 앱이 학생이 입력한 코드를 실행하고, 코드가 올바른지 오류가 있는지 판단한 뒤 그 결과를 Gemini 2.5 Flash AI에게 전달해요.
    입력 데이터: 실행된 코드 내용 + 코드 성공/오류 여부
  단계 3 (조건 분기) — 코드가 성공했는지 오류가 났는지에 따라 AI가 서로 다른 방향으로 피드백을 만들어요. 성공이면 칭찬과 개념 설명, 오류면 힌트 안내로 나뉘어요.
    입력 데이터: 코드 성공 여부 (True / False)
  단계 4 (데이터 조회) — Gemini 2.5 Flash API에 요청을 보내서 고등학교 1학년 눈높이에 맞는 피드백 문장을 받아와요.
    입력 데이터: 코드 내용 + 성공/오류 상태 + '고1 눈높이로 짧게 설명해줘' 요청
    출력/결과: AI가 생성한 피드백 텍스트
  단계 5 (결과 출력) — 오른쪽 화면의 AI 로봇 캐릭터가 말풍선으로 피드백을 보여줘요. 성공이면 로봇이 축하 애니메이션을 하면서 칭찬 메시지와 개념 설명을 띄우고, 오류면 고개를 저으며 힌트를 안내해줘요.
    출력/결과: 말풍선 피드백 텍스트 + 로봇 애니메이션 (축하 또는 고개 젓기)

[ 기능 3: 게이미피케이션 뱃지 시스템 ]
기능 설명: 개념별로 코드를 처음 성공하면 클리어 뱃지가 지급되고 AI 로봇이 축하 애니메이션을 재생. 학생들이 부담 없이 성취감을 느낄 수 있도록 평가가 아닌 보상 중심으로 설계

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 코드 입력창에 파이썬 코드를 작성하고 실행 버튼을 눌러요. 처음 성공한 개념이면 뱃지 지급 대상이 돼요.
    입력 데이터: 학생이 작성한 파이썬 코드, 학생 ID
  단계 2 (시스템 처리) — 앱이 코드를 실행해서 성공 여부를 확인하고, Gemini AI가 결과를 분석해서 칭찬 메시지와 개념 설명을 만들어요. 처음 성공한 개념이면 해당 뱃지를 지급 준비해요.
    입력 데이터: 실행된 코드 결과, 개념 분류(예: print문/반복문), 이전 클리어 기록
    출력/결과: AI 피드백 메시지, 지급할 뱃지 정보
  단계 3 (조건 분기) — 이 개념을 오늘 처음 성공한 건지 확인해요. 이미 뱃지를 받은 개념이면 축하 애니메이션 없이 일반 피드백만 보여줘요.
    입력 데이터: 학생의 기존 뱃지 보유 목록
    출력/결과: 신규 뱃지 지급 여부 (true/false)
  단계 4 (결과 출력) — AI 로봇이 말풍선으로 칭찬 메시지를 보여주고, 처음 성공한 경우 로봇이 축하 춤 애니메이션을 추면서 클리어 뱃지가 화면에 팡! 하고 등장해요.
    출력/결과: AI 칭찬 말풍선, 클리어 뱃지 이미지, 로봇 축하 애니메이션
  단계 5 (시스템 처리) — 학생이 획득한 뱃지, AI 피드백 내용, 클리어한 개념 정보를 DB에 저장해서 나의 성장 기록 페이지에서 언제든 다시 볼 수 있게 해요.
    입력 데이터: 학생 ID, 클리어 개념명, 뱃지 종류, AI 피드백 텍스트, 클리어 시각
    출력/결과: DB 저장 완료

[ 기능 4: 나의 성장 기록 페이지 ]
기능 설명: 학생별 진도, 획득 뱃지, AI 피드백 히스토리를 DB에 저장하고 별도 페이지에서 한눈에 확인. 클리어한 개념과 받은 피드백 이력을 시각화하여 자기주도 학습 동기 부여

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 '나의 성장 기록' 페이지 버튼을 눌러 자신의 학습 기록 화면으로 이동해요.
    입력 데이터: 학생 ID (로그인 정보)
  단계 2 (데이터 조회) — 앱이 데이터베이스에서 해당 학생의 클리어한 개념 목록, 획득한 뱃지, AI 피드백 대화 기록을 가져와요.
    입력 데이터: 학생 ID
    출력/결과: 클리어 개념 목록, 뱃지 목록, AI 피드백 히스토리
  단계 3 (시스템 처리) — 가져온 데이터를 바탕으로 전체 커리큘럼 중 몇 %를 완료했는지 진행률을 계산하고, 개념별 달성 여부를 정리해요.
    입력 데이터: 클리어 개념 목록, 전체 개념 수
    출력/결과: 학습 진행률(%), 개념별 달성 현황
  단계 4 (결과 출력) — 학습 진행률 바, 획득한 뱃지 모음, AI 로봇이 남긴 피드백 히스토리를 한눈에 볼 수 있는 성장 기록 페이지를 화면에 보여줘요.
    출력/결과: 진행률 바, 뱃지 목록 카드, AI 피드백 대화 이력

[ 기능 5: 코드 에디터 및 예제 관리 ]
기능 설명: 줄 번호가 보이는 에디터 스타일의 코드 입력창과 초록색 실행 버튼 제공. 예제 불러오기 버튼으로 커리큘럼 예제 코드를 즉시 로드하고, 초기화 버튼으로 코드를 리셋하여 수업 흐름이 끊기지 않도록 지원

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 코드 에디터에 파이썬 코드를 직접 입력하거나, 예제 불러오기 버튼을 눌러 커리큘럼 예제 코드를 불러와요.
    입력 데이터: 학생이 입력한 파이썬 코드 또는 '예제 불러오기' / '초기화' 버튼 클릭
    출력/결과: 줄 번호가 표시된 에디터 화면에 코드가 채워짐
  단계 2 (데이터 조회) — 예제 불러오기 버튼을 눌렀을 경우, 서버에 저장된 커리큘럼 예제 코드를 가져와요.
    입력 데이터: 선택한 단원명 또는 예제 코드 번호
    출력/결과: 해당 단원의 예제 파이썬 코드
  단계 3 (조건 분기) — 초록색 실행 버튼을 눌렀는지, 예제 불러오기를 눌렀는지, 초기화 버튼을 눌렀는지에 따라 다음 동작이 달라져요.
    입력 데이터: 버튼 클릭 종류 (실행 / 예제 불러오기 / 초기화)
  단계 4 (시스템 처리) — 실행 버튼을 눌렀을 경우, 입력된 파이썬 코드를 서버에서 실행해서 결과값과 오류 여부를 확인해요.
    입력 데이터: 학생이 에디터에 작성한 파이썬 코드 전체
    출력/결과: 코드 실행 결과값 또는 오류 메시지
  단계 5 (결과 출력) — 실행 결과를 오른쪽 AI 로봇 화면에 시각적으로 보여주고, 초기화 버튼을 눌렀을 경우엔 에디터가 빈 상태로 리셋돼요.
    출력/결과: 로봇 말풍선에 실행 결과 표시 또는 에디터 빈 화면으로 초기화

[ 기능 6: 선생님용 커리큘럼 관리 (관리자 모드) ]
기능 설명: 선생님이 자신의 파이썬 커리큘럼 코드를 업로드하면 AI 로봇의 피드백과 예제가 해당 내용에 맞게 자동 조정되는 기능. 다른 정보 교사들도 자신의 수업에 맞게 서비스를 커스터마이징하여 활용 가능 (2차 개발 예정)

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 선생님이 관리자 페이지에 접속해서 자신의 파이썬 커리큘럼 코드 파일(.py 또는 .ipynb)을 업로드하거나 직접 붙여넣기 해요.
    입력 데이터: 커리큘럼 코드 파일 또는 텍스트
  단계 2 (시스템 처리) — AI(Gemini 2.5 Flash)가 업로드된 커리큘럼 코드를 분석해서 어떤 개념이 포함되어 있는지(예: print문, 반복문, 클래스 등) 자동으로 파악하고 단원별로 정리해요.
    입력 데이터: 업로드된 커리큘럼 코드 전체
    출력/결과: 분석된 개념 목록 및 단원 구조
  단계 3 (조건 분기) — 분석이 성공하면 커리큘럼 설정 완료 화면으로 넘어가고, 코드 형식이 맞지 않거나 분석에 실패하면 오류 안내 메시지를 보여줘요.
    입력 데이터: 분석 성공 여부
    출력/결과: 설정 완료 화면 또는 오류 안내 메시지
  단계 4 (데이터 조회) — 설정이 완료된 커리큘럼 정보를 DB에 저장하고, 이후 학생이 코드를 실행할 때 AI 로봇이 이 커리큘럼 내용을 기반으로 피드백을 생성할 수 있도록 불러와요.
    입력 데이터: 저장된 커리큘럼 ID 및 개념 목록
    출력/결과: DB에 저장된 커리큘럼 데이터
  단계 5 (결과 출력) — 선생님 화면에 업로드한 커리큘럼의 단원 목록, AI 피드백 설정 상태, 학생 배포 링크가 한눈에 보이는 관리 대시보드가 표시돼요.
    출력/결과: 단원 목록, AI 피드백 설정 상태, 학생용 서비스 링크

기획서 내용 (아래 형식으로 작성):

[배경 및 필요성]
현재 고등학교 정보 교과에서 인공지능 학습의 선수 과정으로 파이썬 프로그래밍을 지도하고 있으나, 텍스트 기반의 코드 실행 결과(콘솔 출력)만으로는 영상 및 시각적 콘텐츠에 익숙한 현 세대 학생들의 흥미와 동기를 유발하기 어려운 실정이다. 블록코딩(스크래치 등)이 학생들에게 인기 있는 이유는 코드 입력 즉시 캐릭터가 반응하는 시각적 피드백 구조에 있으나, 텍스트 코딩 환경(Google Colab 등)은 이러한 즉각적 시각 반응이 부재하여 학습 흥미 저하로 이어지고 있다. 또한 다수의 정보 교사가 동일한 어려움을 겪고 있어, 개별 교사가 자체적으로 흥미 유발 도구를 제작하기 어려운 구조적 문제도 존재한다. 이에 파이썬 기초 커리큘럼(출력, 변수, 연산자, 자료형, 조건문, 반복문, 함수, 클래스, 모듈)을 시각적·인터랙티브하게 학습할 수 있는 웹 기반 서비스의 개발이 필요하다.

[해결 방안]
본 프로젝트는 바이브코딩(Vibe Coding) 방식을 활용하여 파이썬 학습용 인터랙티브 웹 서비스를 개발한다. 핵심 해결 전략은 다음과 같다.

1. 블록코딩의 즉각적 시각 반응 구조를 텍스트 코딩 환경에 이식: 학생이 파이썬 코드를 작성하고 실행하면, 화면 내 AI 로봇 캐릭터가 코드 내용에 맞게 즉각적으로 애니메이션으로 반응하는 구조를 구현한다.

2. Gemini 2.5 Flash API를 활용한 실시간 AI 피드백: 코드 실행 결과에 따라 AI 로봇이 말풍선으로 칭찬·개념 설명(성공 시) 또는 힌트·오류 안내(실패 시)를 고등학교 1학년 눈높이에 맞게 제공한다.

3. 게이미피케이션 적용으로 자기주도 학습 동기 유발: 개념별 클리어 뱃지, 축하 애니메이션, 나의 성장 기록 페이지 등을 통해 경쟁 부담 없이 성취감을 느낄 수 있는 학습 환경을 제공한다.

4. 확장 가능한 구조 설계: 1차로 학생용 화면을 완성하고, 추후 교사가 자신의 커리큘럼 코드를 업로드하면 서비스가 자동으로 적용되는 관리자 모드를 2차 개발로 추가하여 다수의 정보 교사가 활용 가능한 범용 플랫폼으로 확장한다.

[주요 기능]
1. 코드 에디터 (좌측 화면)
- 줄 번호가 표시되는 에디터 스타일의 파이썬 코드 입력창
- 초록색 실행 버튼
- 예제 불러오기 버튼: 현재 단원의 커리큘럼 예제 코드를 즉시 불러오는 기능
- 코드 초기화 버튼: 작성 중인 코드를 초기 상태로 되돌리는 기능

2. AI 로봇 캐릭터 애니메이션 (우측 화면)
- 귀여운 2D AI 로봇 캐릭터가 화면 중앙에 상시 표시
- 파이썬 개념별 시각적 반응:
  · print문 실행 → 로봇 말풍선에 출력 결과 표시
  · 변수 할당 → 캐릭터 머리 위에 변수 값 표시
  · for문 실행 → range 숫자만큼 로봇 보행 애니메이션 반복
  · if문 실행 → 조건이 True이면 점프, False이면 고개 젓기 애니메이션
  · 함수 정의 및 호출 → 함수에 대응하는 로봇 동작 애니메이션
  · 클래스 정의 → 전사, 궁수 등 캐릭터가 화면에 추가 등장

3. AI 실시간 피드백 (Gemini 2.5 Flash API 연동)
- 코드 실행 성공 시: 칭찬 메시지 + 해당 개념의 쉬운 설명을 말풍선으로 제공
- 코드 실행 실패 시: 오류 원인 힌트 + 수정 방향 안내를 말풍선으로 제공
- 피드백 톤: 고등학교 1학년 눈높이에 맞게 짧고 친근하게 생성

4. 게이미피케이션 및 성장 기록
- 개념별 클리어 뱃지: 각 파이썬 개념(출력, 변수, 조건문, 반복문, 함수, 클래스 등)을 처음 성공하면 뱃지 지급 및 로봇 축하 애니메이션 재생
- 나의 성장 기록 페이지: 클리어한 개념 목록, 획득 뱃지 현황, AI 피드백 히스토리를 한눈에 확인
- DB 연동: 학생별 진도, 획득 뱃지, AI 피드백 히스토리를 데이터베이스에 저장하여 누적 관리

5. (2차 개발) 교사용 관리자 모드
- 교사가 자신의 파이썬 커리큘럼 코드를 업로드하면 서비스에 자동 적용
- 단원별 예제 코드 등록 및 관리 기능
- 학급 학생들의 학습 진도 현황 확인 기능

[기대 효과]
1. 학습 흥미 및 몰입도 향상: 텍스트 출력에서 벗어나 캐릭터 애니메이션과 즉각적인 AI 피드백을 통해 '내 코드가 살아있다'는 경험을 제공함으로써 파이썬 학습에 대한 흥미와 몰입도를 높인다.

2. 자기주도 학습 능력 강화: 게이미피케이션 요소(뱃지, 성장 기록)와 AI 피드백 히스토리를 통해 학생이 스스로 학습 성취를 확인하고 부족한 부분을 재도전하는 자기주도 학습 습관을 형성한다.

3. 교사의 수업 효율성 제고: 학생이 코드 오류 시 AI 로봇으로부터 즉각적인 힌트를 받을 수 있어 교사가 개별 학생 질문에 일일이 응대해야 하는 부담이 줄어들고, 수업 흐름이 원활하게 유지된다.

4. 정보 교육 현장의 범용 도구로 확장: 교사 커리큘럼 업로드 기능(2차 개발)이 추가되면, 전국의 정보 교사가 자신의 수업 내용에 맞게 서비스를 활용할 수 있는 범용 파이썬 학습 플랫폼으로 발전할 수 있다.

5. AI 학습 연계 기반 마련: 파이썬 기초를 흥미롭게 학습한 학생들이 이후 인공지능 교과로 자연스럽게 연결되는 학습 경험을 제공하여, 고교 정보 교과의 AI 리터러시 교육 효과를 높인다.
